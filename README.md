# Text-to-Image Generation using Latent Diffusion
11-785 Course Project (Team 6)


## Installation

* Create a virtual environment with the python==3.9 and activate it

```bash
conda create -n <ENVNAME> python=3.9
conda activate <ENVNAME>
```

* Install all requirements present in the diffusion/requirements.txt folder. 

```bash
pip install -r diffusion/requirements.txt
```
* Login to wandb and add your API Key.

```bash
wandb login
```

```bash
cd diffusion
pip install -r requirements.txt
```

## Usage

* Model Checkpoint:
  The checkpoint to our best model can be found in the model_19.pt file

* Training the model

Run the following commands on CLI to make the model start training. The script.sh file contains the parameters to train the model, the logs get added to wandb.

```bash
cd diffusion
bash script.sh
```
* Visualising the model

Run the following commands on CLI to visualise the diffusion timesteps. The visualise_script.sh file contains the parameters, the logs get added to wandb. The code currently visualises the predictions on the training dataset, the dataloader in the visualise_diffusion() method in the Trainer.py.

```bash
cd diffusion
bash visualise_script.sh
```

## Description of Directories

* baseline_dallE: Our baseline 1 which is a DALLE v1 architecture - this was cloned from their github repository.
* baseline_Lafite: Our baseline 2 which is a GAN based architecture - this was cloned from their github repository.
* diffusion: This folder contains our main implementation of the latent diffusion model and text encoding, and contains the main scripts needed to run and setup this project
* Image Encoder: Contains our the code for our image encoder which was first cloned from Ommer Lab's vq-f4 encoder and then modifications were made.

## Description of Major Files
Here is a description of most important files in the diffusion folder.
* unet.py: Helper modules for the UNet model that is used for the latent diffusion process 
* diffusion.py: Executes DDPM with Cross attention in the latent space
* decode_save_helper.py: Decode latent representations generated by the diffusion process to images 
* main.py: Contains the driver code that takes in arguments and invokes all parts of the pipeline in order
* trainer.py: Loads the data, trains the model and visualises the latent diffusion process
